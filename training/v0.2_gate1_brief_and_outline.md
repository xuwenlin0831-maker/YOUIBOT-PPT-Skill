# YOUIBOT 公司 PPT Skill 培训 v0.2 — Gate 1

## 需求简报

- 目标：让不了解 Skill 的同事能独立完成安装、首次调用、两道审批、HTML 批注、可编辑 PPT 验收和常见排障。
- 受众与场景：以新人为主的现场授课；课后可将 Word SOP 作为操作手册。
- 内容模式：培训/SOP型；其中数据汇报章节只教授数据准备与选图方法，不使用虚构业务数值。
- 核心信息：资料可以不完整，但必须先补问并确认页级大纲；HTML 是可批注的内容合同；PPTX 只在 HTML 明确定稿后生成。
- 期望行为：学员可用本地复制或 GitHub 安装 Skill，并用标准提示词完成一次合规调用。
- 篇幅与密度：28 页、讲师主导、低至中密度；不制作逐页讲师备注。
- 标题：`YOUIBOT 公司 PPT Skill 安装与使用培训`。
- 信息：产品中心-测试组｜林旭文｜2026-09-22｜v0.2｜公开。
- 首页：默认保留半年述职模板官方产业场景图。
- 示例：Demo A 使用已验证的隙锋机器人架构案例；Demo B 只保留未来真实测试数据案例入口。
- 界面图片：统一使用脱敏绘制示意，并标注“界面示意，实际界面可能因版本不同略有变化”。
- 交付：Gate 1 后生成可批注 HTML；同步制作 25–35 页 Word SOP；Gate 2 后才生成可编辑 PPTX。
- 来源优先级：已确认的本轮决策 > 最新正式 Skill > 隙锋 v3 案例 > RobotTest-AI 培训 v0.2 教学结构 > 旧培训 HTML v0.1。
- 未决阻塞项：无。真实测试数据尚不存在，因此不进入本版数值案例。
