# Content modes

Classify every request before Gate 1. Use one primary mode or declare a hybrid and label each outline row with its mode.

## 培训/SOP型

Use for onboarding, classroom training, tool adoption, installation guides, and repeatable operating procedures.

Required narrative elements when applicable:

1. Applicable scenarios and learning outcomes.
2. Fast start that lets a beginner complete one safe path.
3. Concept explanation in plain language.
4. Prerequisites and two installation paths when distribution supports both.
5. Installation verification before first use.
6. First invocation with a copyable prompt and expected result.
7. Gate 1 and Gate 2, including what counts as approval.
8. HTML review and revision loop.
9. Editable-PPT verification.
10. Update, troubleshooting, FAQ/Q&A, and training acceptance checklist.
11. A worked example grounded in verified source material.

Each operational step in a detailed SOP must state: action, expected result, failure symptom, and corrective action. Use only verified screenshots or clearly labeled sanitized UI illustrations. Add the caption `界面示意，实际界面可能因版本不同略有变化` to every mock interface image.

## 汇报/数据型

Use for status reports, weekly/monthly reports, performance reviews, project reviews, product/technical introductions with KPIs, and management decision decks.

Required narrative elements when applicable:

1. Decision question and executive conclusion.
2. Metric definitions and source hierarchy.
3. Current state, target, comparison baseline, and gap.
4. Drivers or root causes supported by evidence.
5. Actions, owner, deadline, risk, and requested decision.
6. Native editable tables and charts rather than screenshots.

Read `data-storytelling.md` before designing quantitative slides. If real data is not available, teach the data-preparation and chart-selection method, label the page as a method/example, and reserve a future case entry. Do not fabricate realistic-looking business numbers.

## Hybrid

Use a hybrid only when the user needs both instruction and decision reporting. Keep the two narrative jobs visibly separated in the outline. Training pages explain how; reporting pages state what the data proves and what action follows.

## Mode acceptance

- Gate 1 brief names the mode.
- Every outline row identifies its mode when hybrid.
- The HTML and PPTX contain no invented facts or unlabeled mock data.
- Training/SOP decks are executable by a beginner; report/data decks are decision-oriented and traceable to sources.
